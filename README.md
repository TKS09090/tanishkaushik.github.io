## Free publishing with GitHub Pages
1. Create a public repository named `yourusername.github.io`.
2. Upload the extracted website files and folders to the repository root.
3. Open **Settings → Pages**. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. Once published, the site will be available at `https://yourusername.github.io`.
